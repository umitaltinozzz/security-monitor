# Contributing to Security Monitor

Thank you for considering a contribution. Please read [the contributor guide](docs/contributing.md) and follow the [Code of Conduct](CODE_OF_CONDUCT.md).

Use the repository issue forms for bugs, feature requests, and false-positive reports. Do not put vulnerability details in a public issue; see [SECURITY.md](SECURITY.md) for private reporting.

By submitting a contribution, you agree that it will be distributed under the repository's Apache-2.0 license.
