# Code of Conduct

## Our commitment

We want participation in this project to be respectful, accessible, and focused on improving the software for everyone.

## Expected behavior

- Be considerate and respectful of differing views and experience.
- Give and receive technical feedback constructively.
- Focus criticism on ideas and code, not people.
- Respect privacy. Do not publish another person's identifying information or confidential security reports without permission.

## Scope

This Code applies in project-managed spaces, including issues, pull requests, discussions, and project events. It also applies when someone is acting as a project representative in a public space.

## Unacceptable behavior

Harassment, discrimination, intimidation, personal attacks, sexualized language or imagery, doxxing, and publishing private information or vulnerability details without consent are not acceptable in project spaces.

## Enforcement

Project maintainers are responsible for clarifying and enforcing this Code. They may remove, edit, or reject contributions that violate it and may temporarily or permanently restrict participation. Maintainers will choose a response proportionate to the behavior, its impact, and any pattern of repeated conduct. Report conduct concerns privately through the maintainer contact channel in [SECURITY.md](SECURITY.md). For conduct reports that are not security issues, do not include sensitive vulnerability details.

This Code is adapted from [Contributor Covenant v3.0](https://www.contributor-covenant.org/version/3/0/code-of-conduct/).
